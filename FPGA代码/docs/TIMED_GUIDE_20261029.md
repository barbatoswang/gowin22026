# 9_5 渐灭提示与节奏评分调试说明

日期：2026-10-29，评分输入、蓝灯与窗口更新于2026-10-30。唯一基础为当前competition_9_5。新旋钮的A18/A17/A19、PULL_MODE=NONE、100μs滤波和四相一步完整保留。未更换音色、App、ESP32或SD格式，未烧录、未写实体SD卡。

## 黄灯提示与重复同键

原GUIDE入口替换为绝对时间节奏训练，不再按对一组才走下一组。准备1500ms后按曲谱时间推进；实际拍点为“开始后1500ms＋曲谱start_ms”。有前奏静默的曲谱第一音不一定在1500ms。

每个琴键维护独立队列，提示该键最早尚未结算的音：

| 当前音剩余时间 | 目标灯效果 |
| --- | --- |
| 大于500ms | 不亮 |
| 500ms | 黄色峰值，归一化值255 |
| 500ms～241ms | 黄色按真实剩余时间逐渐变暗 |
| 240ms～1ms | 突然转为固定亮度蓝色，提示看到就按 |
| 到拍或已过拍 | 熄灭，不自动变绿 |

当前音命中或超时判漏后，看该键下一音的**真实剩余时间**。黄灯基准仍为剩余时间/500：若剩300ms，从3/5亮度继续；若仅剩200ms，已经进入蓝灯区，直接提示蓝色，不重新从满亮走500ms。若下一音也已过拍，不补出假的蓝灯或满亮提示，它仍可在自己的晚按窗口内被命中。

同一颗灯不能同时显示判定色和目标色，所以绿／红先短闪，恢复提示时重新计算剩余时间。例如下一音原剩200ms，绿灯占用60ms后剩140ms，直接进入当前蓝灯区，不补回200ms。密集同键会进一步缩短反馈，优先保留下一拍。

黄色峰值沿用原RGB=10/10/00（十六进制），蓝色默认RGB=00/00/20。归一化值最终量化到灯珠通道数值，暗部会有台阶。每5ms发送一帧，还受串行发送和锁存影响；逻辑拍点设0不代表实物零延迟。LCD琴键也显示同一黄/蓝阶段，到拍提示变暗。240ms是参考视觉反应时间选择的工程默认值，不能保证所有人、所有曲速都自动得到Excellent；详见`BLUE_REACTION_GUIDE_20261030.md`。

## 绿灯与红灯

- 音高正确且在判定窗口内的新起音，才给该键绿色反馈，约60ms。
- 错误音高或无法匹配窗口内待弹音的过早／过晚输入，给实际错误键红色反馈，约100ms。
- 在下一同键音的到拍前20ms，前一次反馈让位于下一提示，不能盖住下一拍的熄灭。
- Miss不伪造按键，不自动变绿。计分中也不因为“实际按下”就直接给绿。
- 自由演奏和AUTO仍用原按键绿色反馈。结束或取消GUIDE后恢复普通灯光语义。

LCD在最近一次判定的琴键附近显示EXCELLENT、GOOD、MISS或WRONG，文字约350ms。和弦各音分别计分，文字只保留最近一次，不代表整组只算一次。

## 判定与整曲等级

误差取FPGA侧收到的有效新起音时刻减去拍点；负数提前、正数迟到。判定输入寄存、排队和RAM扫描不计入误差，但没有自动校准上游键盘扫描或串行发送延迟。

| 判定 | 条件 | 分值 |
| --- | --- | --- |
| Excellent | 正确音，−150ms至+150ms，含边界 | 每音100 |
| Good | 正确音，−300ms至+300ms，但非Excellent | 每音70 |
| Miss | 超过+300ms仍未命中 | 0，自动推进 |
| Wrong | 无法匹配任何窗口内未结算同音事件的新起音 | 每次另扣5，并断连击 |

一次新起音最多消耗一个同音事件，窗口重叠时选误差最近者，等距优先较早者。按错其他键不消耗目标；窗口内可重试正确键，但已有Wrong不撤销。四音和弦逐音判定，不等整组齐了才推进时间；静默事件不计评分。

前1000ms为准备试键区，不计Wrong；最后500ms进入提示与严格输入阶段。持续按住、延音踏板、松键、Note On力度0不能产生新的命中。**连续两个C4必须松开再按。**2026-10-30新增独立的MIDI物理按键状态过滤：同一音未收到Note Off前的重复Note On不再送入评分，因此不会再增加Wrong或消耗下一音；Note On力度0也作为松键处理。踏板只影响发声，松键仍允许下次起音评分。该状态在自由演奏、重播和换曲期间持续跟踪，MIDI通道0的CC120/CC123或FPGA复位清除按住状态。目前不对按住时长、力度或音效打分。矩阵K1～K6是菜单键，不是演奏琴键；板载三音调试键另有接入。

N为整曲非静默音符数，E／G／W分别为Excellent／Good／Wrong数量：

`SCORE = floor(max(0, 100×E + 70×G − 5×W) / N)`，范围0～100。

实时SCORE按整首歌N归一化，初期弹对也只是逐渐累积分数，不是“已弹部分准确率”。Miss与Wrong断连击，四音和弦可计四连击。

| 等级 | 条件 |
| --- | --- |
| SSS | 全部有效音均Excellent、Wrong=0，满分100 |
| SS | 95及以上但未满足SSS |
| S | 90～94 |
| A | 80～89 |
| B | 65～79 |
| C | 0～64 |

10音中9个Excellent、1个Good为97／SS；20音中18个Excellent、2个Good仍为97／SS。计数、连击支持2048事件；Wrong在4095饱和，不回卷。全静默曲谱不评SSS。

最后一音持续时间及判定窗口结束后显示RESULT、等级、计数与MAX COMBO，保留到重播、换曲、切模式或返回。中途停止为取消，不给整曲成绩。若出现INPUT OVERFLOW，结果显示INVALID，应停止重试，不使用这次成绩。

## 上板调试顺序

1. 打开competition_9_5.gprj，使用本次实际验证的新源码及对应码流。IDE旧绿勾和旧FS不能代表新功能，具体码流状态以交付验证记录为准。
2. 保持接线与原卡，不覆盖音库、曲谱或录制槽。进入PERFORMANCE → SONG PLAY。
3. K1/K2选TWINKLE（小星星），K3/K4选GUIDE，K5开始。原App“辅助演奏”发送PG也进入新模式，无需改App／ESP32。
4. 第一遍完全不按：黄灯应渐暗，到拍前240ms转蓝，到拍熄灭；Miss持续增加，曲谱自行结束并结算C，不停在第一音。
5. 再试先用黄色找键、看到蓝灯就按对应键：应闪绿并增加Excellent或Good。声音来自自己的按键，GUIDE不自动代弹。
6. 故意按错误键：它闪红、Wrong增加，声音仍正常发出；目标时间线不等待。
7. 连续同键必须松开再按，下一提示按实际剩余时间接续，不重新满亮；不足240ms时直接蓝灯，一直按住不会给下一音得分。
8. CHORD STUDY可测四音和弦。少按一音不阻止其他音命中，漏音超时后后面的和弦继续。
9. 结果页K5重播，K1/K2换曲、K3/K4换模式清旧成绩，K6停止返回。随后检查AUTO、自由演奏、音色、录制与旋钮八项。

建议PIT=0、OD/CHO/REV/DLY关闭、REL=0、音量适中。音效尾音和踏板不参与判定。SOUND浮窗会暂时遮画面但不暂停曲谱，等其自动淡出即可。停止训练不强制切断仍按住／踏板保持的手动声音。

GUIDE的灯表示“目标及判定”，不是持续按下状态，所以短闪结束后，即便仍按住，灯也可灭；普通模式才按实际按键状态持续亮。LCD可能比实体灯晚一个显示帧，评分不取屏幕显示时刻。
