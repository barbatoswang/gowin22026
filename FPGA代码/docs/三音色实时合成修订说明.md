# competition_9_4 · 三音色实时合成修订

本修订按2026-10-23用户指令更新同一个工程。原电子琴更名“电钢琴”，删除原有限录音电钢琴菜单入口；吉他、萨克斯改为与原电子琴同类的FPGA周期波表合成。旋钮八项、净位移解码、49键灯链、GUIDE、App、曲谱及事件录音格式保持。

## 实时发声机制

三种音色共用`poly_synth_32`的32个独立相位、音高、LFO和ADSR上下文，分时复用算术流水，100MHz时钟、48kHz/16bit输出。一次选用一种全局音色，共32声部，不能把三组波表称为同时96声部。每个音符逐样本累加相位，周期回绕并做相位线性插值及起音/稳定帧交叉渐变，不沿预录音频的时间轴播放。

- 电钢琴：原周期表和原合成参数保留，只改名称。
- 吉他：49键各有起音/稳定音两帧、每周期256点；轻奏更偏柔和频谱，约128ms内过渡到稳定音，持键自然衰减，高音衰减更快。
- 萨克斯：同样采用49键双帧周期；约12ms起音、约64ms频谱过渡，力度影响起音明亮程度。持键不使用自然衰减，松键仍由ADSR/REL控制。

吉他、萨克斯来自保存的真实录音MF层，经离线谐波幅相分析后重建周期。仅谐波特征进入ROM，录音时间轴不进入发声引擎。基音相位对齐、去直流，谐波数上限为`min(64,floor(21600/(2.5*f_note)))`，覆盖当前板级移调、弯音、颤音范围。若以后扩大调音范围，应重新核对混叠边界。生成入口为库根目录`scripts/generate_instrument_wavetables.py`，逐键信息及SHA见[instrument_wavetables.json](instrument_wavetables.json)。

## UI、旧录音和F盘

菜单三行映射为0=电钢琴、2=吉他、3=萨克斯，保留旧吉他/萨克斯编号。退役编号1的旧演奏录音在恢复时映射到实时电钢琴0，目录也显示电钢琴；不改卡上事件、元数据或CRC。录音保存演奏事件，回放由实时引擎重新合成声音。

三种音色发声及切换不等待PCM音库就绪。为尽量保留原SD初始化、本地曲谱FIFO路由及安全存储，F盘`TONES49.BIN`仍按原启动流程加载至DDR；它与音频输出断开，PCM引擎保持复位、采样缓存不启用。SD曲谱/录音服务仍需等待原启动流程完成，原56秒以上大音库等待没有在本轮重构。

原Iowa录音四个ZIP保存在库内`references/archives/instrument_samples_20261017/`，原规范化录音镜像保存在旧发布包及F盘。原采样源档、分段和校音记录继续保留。不得删除或覆盖这些资料作为“清理无用音库”。9_4于2026-10-23对F盘做过只读文件校验；9_5本轮未访问或改写实体卡。
