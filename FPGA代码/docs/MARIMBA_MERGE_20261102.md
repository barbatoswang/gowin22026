# 9_5新增马林巴音色

日期：2026-11-02。以用户当前competition_9_5为主线，从competition_10_2只合入第四音色及必需的选音、录音、显示链路。本轮未运行Gowin综合、布局布线、烧录或实体SD操作。

## 使用方式

PERFORMANCE -> TONE SELECT现在有四项：电钢琴、吉他、萨克斯、马林巴（MARIMBA）。K3/K4切换，K5确认，K6返回。当前音色角标、曲谱演奏页及录音目录同步支持马林巴。

| 编号 | 音色 |
| --- | --- |
| 0 | 电钢琴 |
| 1 | 退役的旧录音电钢琴编号，继续映射0 |
| 2 | 吉他 |
| 3 | 萨克斯 |
| 4 | 马林巴 |

四种音色共用32声部实时合成引擎，一次选择一种全局音色。AUTO曲谱与事件录音原有四音通路保持。GUIDE绝对节奏评分、黄灯渐灭、提前蓝灯、绿/红反馈、等级与输入过滤保持。

马林巴是敲击后自然衰减的音色：按住也会逐渐变轻，不像持续吹奏的萨克斯。沿用10_2约1ms起音、起音/余音频谱渐变、随音区变化的自然衰减以及力度明亮度控制；REL继续控制松键释放。新音色仍经过原音量、过驱、合唱、混响、回声、移调和颤音链路。

## 合入内容

- 新增marimba_wavetable_rom.v和两份8192词MEM，49键、起音/余音两帧，半周期镜像恢复256相位点。
- 音色编号从2位扩为3位，贯通tone_controller、菜单、poly_synth_32、顶层和显示。
- 乐器ROM组读取从两拍统一为三拍，合成流水配套增加等待状态；旧三音色波表不变。输出仍在下一音频tick前完成，不新增整音频帧延迟。
- 录音音色目录由16×2位扩为16×3位。TAKE头本来已有32位metadata，使用[18:16]记录音色，[15:0]仍为时长；事件载荷、CRC、双副本结构、文件大小均保持。旧0/1/2/3编号继续兼容。
- 回放会采用录音音色，结束、取消或错误后恢复用户原来的手动音色；原手动马林巴也能恢复。
- 同步本地record_slots.py、convert_recording.py，能正确识别/生成音色4，不把它截为0。
- GPRJ/build.tcl新增ROM模块引用一次；MEM按readmemh相对路径随工程保存。

原录音素材只用于离线提取周期谐波特征。FPGA读取的是周期波表，不是完整录音时间轴。来源说明、源文件登记、波表参数和生成工具随10_2一并保留在marimba_source、marimba_wavetables.json与tools中；编译只需已生成的MEM，无需下载原录音。
