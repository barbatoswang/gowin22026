# 03 - 单音合成与板载 DAC 烧录验证

## 本阶段实现的完整通路

```text
板载 50 MHz 时钟
        |
        v
PT8211 串行帧时序 ----> sample_tick（48 kHz）
        |                         |
        |                         v
        |                 DDS 32位相位累加器
        |                         |
        |                         v
        |                  256点正弦波表
        |                         |
        |                         v
        |                    右移3位衰减
        |                         |
        +<----- 左右声道相同的16位样本
        |
        v
板载 PT8211 DAC -> 3.5 mm 音频输出
```

上电后持续实时生成 440 Hz 正弦波。系统没有保存或播放任何一段 PCM 录音；每个
采样点均由 DDS 相位和单周期波表实时产生。

## 为什么板载接口不是标准 I2S 时序

PT8211 使用 Japanese/LSBJ 串行格式：

- BCK 上升沿采样数据；
- WS 低电平为右声道；
- WS 高电平为左声道；
- 每个声道 16 位补码，MSB 先发；
- 左右声道紧邻发送，没有标准 I2S 的一位延迟。

本阶段的 `pt8211_tx` 专门匹配板载芯片。以后使用标准 I2S DAC 时，会新增独立的
`i2s_tx` 模块，不修改 DDS、音色或混音模块。

## 时钟关系

```text
采样率（WS）        = 48,000 Hz
每帧数据位          = 16 bit x 2 channel = 32 bit
BCK                  = 48,000 x 32 = 1.536 MHz
BCK上升/下降沿事件率 = 1.536 MHz x 2 = 3.072 MHz
```

3.072 MHz 的边沿事件由 50 MHz 系统时钟中的累加器时钟使能产生。FPGA 内部所有
状态仍只使用 50 MHz 时钟，不把 HP_BCK 当作内部逻辑时钟。

## 输出音量

正弦样本在送入 DAC 前算术右移 3 位：

```text
幅度 = 满量程 / 8
增益约为 -18.06 dB
```

这是为了让第一次耳机测试保持较低音量。仍建议先将耳机放在桌面上确认声音，再佩戴。

## LED状态

板载 LED 为低电平点亮：

| LED | 正常现象 | 含义 |
|---|---|---|
| LED0 | 约 1 Hz 闪烁 | 48 kHz立体声音频帧持续运行 |
| LED1 | 常亮 | 内部同步复位已经释放 |
| LED2-LED5 | 熄灭 | 当前阶段未使用 |

按下 S0 时，LED0和LED1熄灭，DAC输出归零；松开后音频重新开始。

## 烧录步骤

1. 在 Gowin IDE 中重新打开 `competition.gprj`。
2. 确认顶层模块为 `competition_top`。
3. 执行 Synthesize、Place & Route 和 Generate Bitstream。
4. 使用 Programmer 将 `impl/pnr/competition.fs` 下载到 SRAM。
5. 按一次 S0，使所有寄存器经过明确复位。
6. 观察 LED1常亮、LED0闪烁。
7. 将耳机或有源音箱连接到3.5 mm接口，应该听到连续、稳定的低音量440 Hz纯音。

## 从外到内的调试顺序

如果没有声音，按以下顺序排查：

1. LED1不亮：检查 `rst_n`、K16约束或按键是否一直处于复位状态。
2. LED0不闪：检查系统时钟P16、`sample_tick`和PT8211帧计数。
3. LED正常但无声：检查3.5 mm接口、耳机/有源音箱和音频管脚约束。
4. 使用逻辑分析仪检查：HP_BCK约1.536 MHz，HP_WS约48 kHz。
5. 检查HP_DIN是否随相位变化；如果始终为0，继续检查DDS和正弦波表。
6. 如果频率不对，检查`A4_PHASE_INCREMENT`和实际`SAMPLE_RATE_HZ`。

## 当前局限

- 只有一个持续发声的440 Hz声部；
- 尚未加入按键触发和ADSR，因此声音没有起音/释音过程；
- 256点波表适合功能验证，后续将升级为更高分辨率ROM；
- PT8211 BCK采用分数时钟使能，后续可通过音频PLL进一步降低时钟抖动。
