# Tang Mega 138K Pro Dock 实测管脚表

本文件记录当前参赛开发板经过实板验证的管脚关系。后续约束优先以这里的实测结果为准，
不直接照搬可能存在版本差异或标注错误的官方例程。

## 板载按键

所有按键均为低电平有效：松开为高电平，按下为低电平。

| 物理按键 | FPGA管脚 | 当前用途 | 验证状态 |
|---|---|---|---|
| S0 | K16 | 采样组循环选择 `rst_n`（低有效） | 已验证 |
| S1 | F15 | 预留 | 已确认映射 |
| S2 | G15 | 当前单音触发 `note_key_n` | 已验证 |
| S3 | G16 | 预留 | 已确认映射 |

按键输入约束应使用内部上拉：

```cst
IO_PORT "signal_name" IO_TYPE=LVCMOS33 PULL_MODE=UP DRIVE=OFF BANK_VCCIO=3.3;
```

| 系统时钟 | P16 |

## 板载PT8211音频DAC

| 功能 | 顶层信号 | FPGA管脚 |
|---|---|---|
| 位时钟 | `HP_BCK` | E22 |
| 左右声道选择 | `HP_WS` | F24 |
| 串行音频数据 | `HP_DIN` | G24 |
