# competition_9_2 数字音频效果

输出链：音源混音 → 合唱 → 回声 → 混响 → 过载 → 换音色淡入淡出 → PT8211。三种空间音效全为0时走9_1原干声路径。新增效果默认关闭，四种音色共用；左右声道仍输出相同样本。

| 处理 | 控制与实现 |
| --- | --- |
| 合唱CHO | 0～32；0.5Hz三角LFO，192～319采样延迟（约4～6.65ms），湿声最大1/2 |
| 回声DLY | 0～32；8192采样（约170.67ms），湿声最大1、反馈最大1/2 |
| 混响REV | 0～32；1493/1867/2203采样三条梳状支路，反馈各1/2；紧凑单声道混响，未加全通扩散 |
| 过载OD | 0～4软削波，0关闭 |
| 压缩/限幅 | 保留混音分段压缩，各新增效果级有符号饱和，防止数值回卷 |
| ADSR | 每声部独立；A/D/S默认，主旋钮第八项REL为0～8档 |
| 颤音VIB | 本地0～8档，每档4音分；与CC1相加限制127音分，音源LFO仍为5Hz |
| 移调/弯音 | 主旋钮PIT为±12半音；MIDI Pitch Bend保持 |
| 力度/踏板 | 原非线性力度增益、CC64保持与释放 |
| 切音 | 保留淡出、静音提交和淡入；效果缓存尾音可继续衰减 |

VOL0同时静音干声及效果尾音。非零音量调节影响音源激励，已经存入缓存的尾音按反馈衰减。关闭某效果会旁路其湿声；缓冲继续运行，重新打开时可能听到近期尚未衰减的声音。

各级通过完成脉冲处理同一帧，不分别等待下一次48kHz节拍。音效单元测试实际最大23个100MHz时钟完成；整机测试检查DAC采样期限。该算术时间不是无线、串口和模拟输出的端到端实测延迟。

电子琴32个独立波表声部；电钢琴/吉他/萨克斯升级为各32PCM声部。PNO1曲谱/录音容量和格式不变。李萨如显示中的32点延迟不计作音频回声；本次未增加EQ或立体声效果。

原LongScores App、JSON、PT8211与SD文件保持。实际资源/时序见[验证摘要](验证摘要.md)，听感、延迟、温升及完整比赛验收仍需上板。

做32声部独立频谱演示时先将OD/CHO/REV/DLY设为0，避免非线性失真和调制侧带干扰对振荡器数目的解释；音效另用冲激或单音开启/关闭对比演示。
