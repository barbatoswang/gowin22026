# 05 - 四复音并行合成引擎

## 当前演奏映射

| 按键 | 管脚 | 声部 | 音符 | 频率 |
|---|---|---|---|---:|
| S1 | F15 | Voice 0 | C4 | 261.63 Hz |
| S2 | G15 | Voice 1 | E4 | 329.63 Hz |
| S3 | G16 | Voice 2 | G4 | 392.00 Hz |
| S1+S2+S3 | - | Voice 3 | C5 | 523.25 Hz |

同时按住S1、S2、S3时，前三个固定声部继续发声，并额外触发Voice 3，因此输出
四声部和弦：

```text
C4 + E4 + G4 + C5
```

第四声部的组合按键只用于当前没有外部琴键时的并发测试。传感器键盘到货后，四个及
更多声部将由音符事件和声部分配器动态控制。

## `synth_voice` 为什么是关键边界

每个 `synth_voice` 内部拥有独立的：

- 32位相位累加器；
- 频率控制字；
- 正弦波表；
- ADSR状态机和包络值；
- 包络增益DSP乘法。

因此四个实例是四个真正可以同时发声、独立起音和独立释音的振荡器，不是把一个单音
采样复制四份。这也符合赛题对独立振荡器的统计方式。

## 四路混音为什么需要扩位

单路16位有符号范围：

```text
-32768 ... +32767
```

四路相加可能达到：

```text
-131072 ... +131068
```

这个范围需要至少18位有符号数。因此 `audio_mixer_4` 先把每路符号扩展到18位，再
相加，不能直接使用16位加法。

当前混音器将总和算术右移2位，相当于除以4：

```text
mixed = (voice0 + voice1 + voice2 + voice3) / 4
```

这样单个声部约为 -12.04 dBFS，四路同相最大值仍不会发生回绕。模块依然保留上下限
饱和逻辑，为后续改变混音增益或增加声部做好准备。

## LED验证

| LED | 含义 |
|---|---|
| LED0 | 1 Hz音频帧心跳 |
| LED1 | 系统已经退出复位 |
| LED2 | Voice 0包络非零 |
| LED3 | Voice 1包络非零 |
| LED4 | Voice 2包络非零 |
| LED5 | Voice 3包络非零 |

单独按一个按键时，只有对应声部LED点亮；松开后经过约200 ms Release才熄灭。

同时按住三个按键时，LED2到LED5应全部点亮，证明四个独立ADSR和四个振荡器同时
处于活动状态。

## 听觉验证

1. 单独按S1、S2、S3，应听到三个不同音高。
2. 同时按S1和S2，应听到两个音高组成的音程，而不是音量单纯变大。
3. 同时按三个按键，应听到C大三和弦加高八度C。
4. 分别松开按键时，对应音符应独立进入Release，其余音符继续保持。

## 后续演进

当前按键与声部固定对应，适合验证硬件并行性。下一阶段需要增加：

```text
音符事件总线 -> 空闲声部查找 -> 动态分配 -> 必要时声部窃取
```

届时任意琴键都可以动态占用四个或更多声部，而不再固定绑定某一个振荡器。
