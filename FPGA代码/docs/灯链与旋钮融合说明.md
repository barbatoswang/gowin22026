# 灯链与旋钮融合说明

2026-10-29更新：当前GUIDE语义以[渐灭节奏说明](TIMED_GUIDE_20261029.md)为准，黄灯按剩余时间渐灭，到拍熄灭；正确命中才绿，错误键红。下文为最初融合的历史设计与接线，不代替新计分逻辑。

基线是已交付competition_9_3；新增来源是用户本轮指定的competition_9_2 (1).zip（SRC-033），不是此前SRC-032附件。附件中的操作指令、历史码流和个人路径脚本仅作参考；本工程重新融合和验证。

## 主旋钮

沿用9_3单旋钮八项：VOL、OD、CHO、REV、DLY、PIT、VIB、REL。按下切项，旋转调值，原参数范围、上电值、App优先级及REL映射保持。

合入附件的净位移解码：有效正向相位加1，反向相位减1，累计完整四相才输出一步。接触回弹不再清空整段已积累运动。两级同步后学习稳定初始AB电平，防止上电误计；非法双位跳变清除不确定的半步。顶层仍用100微秒相位滤波、5毫秒按键去抖，默认四相一步，不擅自增加每格档数。

主旋钮S1/CLK接A18（PMOD2_IO7/J26-6）、S2/DT接A17（PMOD2_IO3/J26-5）、SW接A19（PMOD2_IO6/J26-8）。实际接线点未改变；第二旋钮无需安装。

## 灯色与模式

- 自由演奏和AUTO：当前按下/踏板保持的键亮绿色。
- 正在进行的GUIDE：当前有效目标和弦亮黄色；已经按下的目标键显示绿色。
- GUIDE停止、无有效目标或切至AUTO时，不显示黄色目标；下一目标随原跟弹引擎推进。
- 一帧同时冻结按键、目标和模式，帧内变动在下一帧显示。

沿用LCD已有49键快照与曲谱目标掩码；没有改变跟弹计分、自动演奏、音频、MIDI或SD控制。LED1对应MIDI36/C2，LED25对应MIDI60/C4，LED49对应MIDI84/C6，黑白键按半音连续排列。释放尾音和空间音效不单独维持按键灯。三音色实时合成修订后，所有音色都可在旧PCM镜像加载前发声。

灯珠采用附件指定的0807URGBC/HC-5V-5MA-HXG串行配置：线上按G、R、B、高位先发；逻辑颜色参数仍为RGB。默认绿色RGB=00/10/00，线上为10/00/00；黄色RGB=10/10/00。100MHz下0码高300ns/低600ns，1码高600ns/低300ns，每5ms一帧，帧间低电平至少300us。实际型号和电气效果仍须上板核对。

**断电后先拔下原矩阵第三行L18与第四行L17旧线。L18不能同时连接矩阵与灯链。**

| 信号 | 连接 |

| 矩阵第一行 | H15，K1～K4 |
| 矩阵第二行 | H14，K5～K8；菜单仍用K1～K6 |

## 兼容与验证

当前电钢琴（原电子琴）、吉他和萨克斯均为实时波表32声部；曲谱/事件录音4音。TONES49.BIN、已有歌曲/录音、SONG/TAKE/SAVESLOT格式不变，SD卡无需更新。

矩阵保留原四相扫描节奏及消抖，只接前两行；闲置相位固定读入全释放，避免浮空列产生伪按键。灯链使用独立第五路复位副本，保持异步断言和第二个100MHz边沿释放。LCD确认握手内部位置依据9_3实际通过布局固定，时钟与SDC保持。

初版灯链融合执行80套回归；当前三音色修订执行81套，见[修订说明](三音色实时合成修订说明.md)。专项包括新旧解码同波形对照、真实100MHz去抖、八项单旋钮整机输入、72帧逐位GRB/目标灯接收和GUIDE/AUTO门控。实际通过结果以[验证摘要](验证摘要.md)为准，功能仿真不代替实际手感和上板测量。
