# 七色单音与白色合成波形

日期：2026-10-31。基础：当前competition_9_5，保留2026-10-30蓝灯、评分窗口和MIDI按键过滤。

## 屏幕效果

进入原WAVEFORM波形页即可查看。按当前仍在发声的声部的起音先后，最多显示七条彩色波形：

| 显示顺序 | 颜色 |
| --- | --- |
| 1 | 红 |
| 2 | 橙 |
| 3 | 黄 |
| 4 | 绿 |
| 5 | 蓝 |
| 6 | 靛 |
| 7 | 紫 |

另有较粗的白色总波形，右上角标为MIX ALL。底部各色方块与音名来自同一帧采样，显示的是实际移调后的音高，例如C4或C#4。

上限七条只作用于彩色分量显示。第8～32个音仍正常实时合成、发声并进入白色总波形，频谱也仍分析完整最终输出。较早声部结束后，后面的声部按起音顺序补入，剩余音的颜色可能随排名前移。延音踏板和ADSR释放尾音在声部实际结束前仍算发声声部；同一硬件声部被重新触发或复用时，按新起音重新排序。真正同一时钟开始的音按声部编号确定次序；连续时钟到达的起音按到达先后排队，不按编号插队。

## 单音与总波形的含义

彩色线取自真实32声部合成器，每个采样已包含该声部的波表音色、实时频率/移调、自然衰减、ADSR和声部增益。这里没有另外制造显示用正弦波。

白色线取自原`final_audio_sample`，即最终输出，包含全部发声声部及总增益、限幅、合唱、回声、混响和过驱等处理。彩色分量位于这些总线处理之前，因此白线不一定等于屏幕上七条线的像素值简单相加；超过七个声部的部分也包含在白线中。

频谱、李萨如、菜单、音色、录音、蓝灯节奏评分、App、ESP32、SD格式和引脚不因本次显示改动而调整。

## 同步与资源

七条分量和总波形共用一次触发、同一个采样索引和一组双缓冲，横轴保持每像素一个48kHz采样点，800点约16.67ms。起音顺序、显示声部和音名在一帧内一致；采集过程中分量归属变化时重新采集整组，避免一条线中途更换音符。LCD只在帧边界切换波形与图例，未显示完成的缓冲区不会被写端覆盖。

屏幕原本按16位音频右移8位绘制，本版直接保存其高8位作为显示样本，保留原±128像素量级的显示精度。音频仍为原16位，未改变音频采样率或32复音算法。绘制时连接相邻列的波形位置，使高频陡坡连续；白色总线加粗，彩线保持较细。

原实现报告使用308/340块BSRAM。新显示RAM声明为2048×64位，取代原2048×16位显示RAM，另有一个很小的起音顺序FIFO；实际映射资源与时序仍以重新综合/布线报告为准。本次没有跑新的综合和布局布线。

## 代码位置

- `src/synth/poly_synth_32.v`：新增只读声部采样输出，不改变原音频状态机。
- `src/video/waveform_voice_monitor.v`：起音顺序FIFO、32声部排序、选取前七条、按DAC采样点冻结显示数据。
- `src/video/waveform_multichannel_buffer.v`：八路8位显示采样、双缓冲和音名元数据同步。
- `src/video/waveform_multitrace_renderer.v`：七色细线、白色总线、相邻列连线与底部音名。
- `src/top/competition_top.v`：把这些显示模块接入原波形页，其他页面仍经过原渲染通路。
