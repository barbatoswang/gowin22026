# 显示接口与检查

## 数据与时钟

主音频为100MHz用户域、48kHz采样、16位有符号PCM。`waveform_voice_monitor`在sample_tick冻结32声部的活动状态/音名及选中分声部，延后48个100MHz时钟读取最终效果混音；不修改音频数据。177位包由64位八路样本、97位元数据和16位触发样本组成，经REQ/ACK保持握手跨到50MHz缓存域。缓存按LCD帧边界交换显示页，保持样本、音名、有效标志同帧。

`waveform_packet_cdc`源/目标复位分别在所属时钟域同步释放。显示缓存读口在10MHz LCD域，为同步RAM，top用x+1提前给地址；实际扫描坐标用于最后合成。跨域握手压力、复位和同帧稳定性均由专用回归覆盖。

## 波形

原8位有符号显示样本扩展到有符号12位后左移1位，再计算`240 - sample*2`。显示纵坐标钳制82～399，网格/零线与y=240同步；不会因负数或极值发生无符号回绕。图例y=408～437，底部状态从y=440开始。彩线厚3像素，白线厚5像素，显示标签X2。

幅度2倍是显示比例，不是音频增益。白线来自最终全声部混音，彩线是各独立声部；因此音效、饱和和混音缩放会使它们具有不同形状/比例，不应逐像素相加判断声音是否正确。

## 李萨如

`mono_phase_pair`在同一sample_tick寄存X和延迟Y，让同沿消费者取得严格相差32个采样的上一组成对数据。相对附件修正了X直通、Y寄存导致的33采样实际间隔。

16位有符号样本以COORD_SHIFT=7映射到0～127，越界饱和；内部双缓冲位图仍为128×128，未新增图像RAM。显示画布x=240～559、y=100～419，大小320×320，中心(400,260)，正Y向上。显示坐标到内部位图用floor(coord*128/320)，网格和边框按同一几何参数计算。相同未饱和输入相对附件位移为2×320/256=2.5倍。

输入是同一音频的延迟对，不能称作两个独立声道。静音聚集在中心；单频可形成线或椭圆，复音/非正弦可出现复杂轨迹；本版没有自动增益，极大信号会饱和到边缘。

## UI验证范围

`sim/tb_zoom_ui.sv`使用生产LCD扫描器、同步波形RAM、李萨如位图RAM、基础渲染器、七彩叠加层及常驻音色/SD叠加层；按800×480完整帧逐像素输出。正常页的其他专用图层不激活，SOUND浮窗隐藏；用户调参时浮窗临时覆盖绘图区属于既有交互行为。

四项场景分别检查放大波形、孤立波形列边界、李萨如角点/中心22像素、相图圆形预览。断言覆盖正负号、饱和、真实RAM一像素对齐、不同页面透传。预览采用已知确定性样本/位图夹具，用于几何和图层检查；效果链与监视器、32采样间隔另用生产数据通路测试，均不代替实物LCD验收。
