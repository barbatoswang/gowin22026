# 专用SD保存槽

FAT32根目录固定文件SAVESLOT.BIN，65536字节，即128个512字节扇区。固件只定位并使用该文件现有FAT链；支持分散簇，不分配新簇、不写FAT或目录。首次部署由电脑创建，后续保留已有文件。

存储加载修订中，音库读取与保存槽均识别FAT32的有效副本选择字段；关闭镜像且选择副本1时，不再误读过期副本0。MBR四槽与跨簇根目录也按各自实际链查找。原曲谱槽格式、扇区布局及写入顺序保持。

扇区0为不改写的标识：ASCII C6SLOT01；偏移8/12/16/20为LE32的65536/1/65/8200；偏移24为前24字节的标准CRC32。文件名、长度、标识或CRC不合格时禁止写入。文件簇链越界/循环/重复扇区会报错。

双副本头位于文件扇区1和65，各自数据从下一扇区开始。头部ASCII C6SCORE1；偏移8为LE32代号；12/14为LE16的字节长度/事件数；16为LE32负载CRC；20保留0；24为前24字节CRC；28为代号按位取反。负载是完整PNO1，16～8200字节。各副本最多使用17个数据扇区，其余保留。

保存顺序：锁定SD共享总线→作废非当前副本头→写新负载→最后提交头→读回头和负载校验→标记SAVED并切换当前副本。失败不覆盖原有效副本；上电分别验证头CRC、PNO1头与负载CRC，再选最新有效代号，支持代号回绕。

RAM上传与SD保存通过稳定元数据、toggle握手和Gray指针双时钟FIFO交接。ACK:E仅表示曲谱可用于当前运行；持久化以SAVED为准。保存过程中新的SB会返回ERR:BUSY。没有保存槽时RAM功能保留，不会创建其他文件。

启动先完成音库/曲目目录读取，随后保存槽才能获得SD总线。用户在此期间可使用默认电子琴和远程RAM曲谱；持久化排队等候。新的远程上传优先于迟到的上电恢复，恢复FIFO会排空旧数据，避免旧曲覆盖新曲。

验证包含SPI级512字节/CRC16/错误响应/忙超时、FAT块模型中的分散簇、最大负载、双副本、半途掉电、写失败、读回CRC失败和标识写保护。真实SD卡的内部缓存、介质损坏、电源中断及耐久性尚未上板测量；双副本不替代外部备份。
