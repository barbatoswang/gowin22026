# 04 - 按键触发与 ADSR 包络

## 为什么不能直接把按键接到声音开关

机械按键有两个问题：

1. 按键与 50 MHz 时钟没有同步关系，直接使用可能引入亚稳态。
2. 触点按下和松开时会在数毫秒内反复抖动，可能生成多次 Note On/Off。

`button_debounce` 先用两级触发器同步，再要求输入连续稳定 3 ms 才接受状态变化。
模块同时输出稳定电平以及单周期的按下、松开事件。

## S2 的行为

```text
S2松开：note_key_n = 1
S2按下：note_key_n = 0
```

经过同步消抖后得到高有效 `note_gate`：

```text
按住S2：note_gate = 1
松开S2：note_gate = 0
```

## ADSR状态机

```text
IDLE --按下--> ATTACK --> DECAY --> SUSTAIN
                                      |
                                      | 松开
                                      v
IDLE <--------------- RELEASE <-------+
```

默认参数：

| 阶段 | 参数 | 含义 |
|---|---:|---|
| Attack | 20 ms | 从静音线性上升到最大音量 |
| Decay | 80 ms | 从最大音量下降到保持音量 |
| Sustain | 60% | 按住按键期间保持的音量 |
| Release | 200 ms | 松开后平滑衰减至静音 |

## 为什么内部使用 Q16.16

包络输出是 16 位无符号增益，但内部使用 32 位 Q16.16：

```text
高16位：对外可见的包络幅度
低16位：每个采样点不足1 LSB的小数变化
```

如果只用16位整数，在慢速Decay和Release中步长必须取整，实际时间会产生明显误差。
Q16.16保存小数余量，使毫秒参数更准确。

## 音频增益乘法

`audio_gain_apply` 执行：

```text
有符号16位正弦样本 × 无符号Q0.16包络增益
```

内部把增益扩展成17位正数再执行有符号乘法，避免 `16'hFFFF` 被误认为 `-1`。

乘积右移16位用于消除包络小数位，再额外右移3位，使最大音量保持在约 -18 dB。

## 硬件测试现象

烧录后按一次S0，再测试S2：

| LED | 现象 | 含义 |
|---|---|---|
| LED0 | 1 Hz闪烁 | 音频帧正常运行 |
| LED1 | 常亮 | 系统已退出复位 |
| LED2 | 按住S2时亮 | 消抖后的Note Gate |
| LED3 | 从Attack开始亮，Release结束后灭 | 包络仍非零、声音仍在输出 |
| LED4 | 进入Sustain后亮 | 当前处于保持阶段 |
| LED5 | 熄灭 | 保留 |

听觉上应表现为：

1. 按下S2，440 Hz声音快速但非瞬间地渐强。
2. 继续按住，声音先略微回落，然后保持稳定。
3. 松开S2，声音在约200 ms内逐渐消失，而不是立即截断。

## 调试顺序

1. 按S2时LED2不亮：检查G15约束、按键有效电平及消抖模块。
2. LED2亮但LED3不亮：检查`sample_tick`和ADSR状态机。
3. LED3亮但无声：检查包络乘法、DDS、PT8211和音频输出。
4. 松开后声音不消失：检查Gate是否回到0以及Release状态。
5. 每次按下出现多个起音：增加`DEBOUNCE_MS`，并查看原始按键波形。

3 ms消抖只用于当前板载机械按键验证。最终电容触摸、压力和ToF传感器将使用各自的
数字滤波策略，不会统一套用机械按键消抖时间。
