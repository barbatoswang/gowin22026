# 02 - DDS 相位累加器

## 这个模块解决什么问题

声音的音高由周期频率决定。FPGA 中不适合使用浮点三角函数逐点计算正弦波，因此采用
DDS（Direct Digital Synthesis，直接数字频率合成）：

1. 使用 32 位寄存器保存当前相位。
2. 每个音频采样点增加一个固定的相位步长。
3. 32 位加法自然溢出后回到起点，形成周期运动。
4. 将相位送入波表即可得到正弦波、三角波等波形。

## 频率公式

```text
phase_increment = round(frequency_hz * 2^32 / sample_rate_hz)
```

在 48 kHz 采样率下生成 440 Hz 的 A4：

```text
phase_increment
= round(440 * 4,294,967,296 / 48,000)
= 39,370,534
= 0x0258BF26
```

使用该整数得到的实际频率约为 440.000005 Hz，误差可以忽略。

## 接口

| 信号 | 方向 | 说明 |
|---|---|---|
| `clk` | 输入 | 50 MHz 系统时钟 |
| `rst_n` | 输入 | 低有效异步复位 |
| `sample_tick` | 输入 | 新音频采样点使能 |
| `enable` | 输入 | 允许相位运行；为 0 时保持当前相位 |
| `phase_reset` | 输入 | 将相位同步清零，优先级高于采样更新 |
| `phase_increment` | 输入 | 32 位频率控制字 |
| `phase` | 输出 | 32 位当前相位，供波表或 FM 模块使用 |
| `saw_sample` | 输出 | 由相位高 16 位形成的有符号锯齿波 |

## 为什么相位和波形分开

相位累加器只负责“以多快的速度绕一圈”，波形模块负责“这一圈映射成什么形状”。

同一个 `phase` 后续可以连接到：

- 正弦波表；
- 方波比较器；
- 三角波变换；
- FM 调制器；
- 多波表音色选择器。

这样更换音色时不需要重新实现频率控制逻辑。

## 锯齿波输出

`phase[31:16]` 是从 `0` 到 `65535` 递增的无符号斜坡。将最高位翻转：

```verilog
phase[31:16] ^ 16'h8000
```

即可映射为 16 位有符号范围：

```text
-32768 ... +32767
```

锯齿波目前主要用于验证 DDS 是否工作；比赛最终音色会使用正弦波表和 FM 合成。

## 测试平台检查内容

`tb_dds_phase_accumulator.v` 自动检查：

1. 复位后相位为 0。
2. 没有 `sample_tick` 时相位不变化。
3. `phase_increment = 2^29` 时，8 个采样点完成一个周期。
4. 32 位溢出能够自然回到 0。
5. `phase_reset` 能清零相位。
6. `enable = 0` 时相位暂停。
7. A4 频率控制字运行 48,000 个采样点后恰好发生 440 次相位回绕。

正确输出应包含：

```text
PASS: phase control, wrapping, enable and 440 Hz test passed.
```

## 常见调试问题

如果音高完全不对，先检查频率控制字是否按照实际采样率计算。

如果音高相差 2 倍，通常是采样率、左右声道帧率或相位位宽理解错误。

如果相位每个 50 MHz 时钟都变化，说明忘记使用 `sample_tick` 作为时钟使能。

如果停止音符后再次播放从随机相位开始，检查 Note On 时是否产生了一个周期的
`phase_reset`。
