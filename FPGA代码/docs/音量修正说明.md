# competition_7 声音调整

保留competition_5的四声部流水线、短Release、PCM有效数据等待和有限窗口。原competition_5音量修订将混音/4改为/2，提高了小信号输出，但极端四音同相容易进入硬饱和。新压缩包采用/4保留余量，直接照搬会恢复音量偏小。因此本版采用/2的小信号增益及分段峰值压缩。

令四个有符号16位声部之和为S，先算B=S算术右移1，M=abs(B)。压缩幅度为：M≤16384时M；16384<M≤32768时16384+(M−16384)/2；M>32768时24576+(M−32768)/4。恢复符号后送原音量、过载、音色淡入淡出及PT8211通路。整数截断在段界连续，最坏四个−32768输出−32768、四个+32767输出+32767，不发生正负翻转。

该压缩器5级100MHz寄存流水，不做跨帧反馈；低幅单音保持原+6.02dB方向，高幅和弦压缩而不直接削成平顶。指示信号clipping在本模块表示进入压缩区，并非已经发生数值溢出。过载是用户主动的非线性效果，OD0为关闭；这里的峰值压缩仍工作。

PT8211发送器保留原BCK、WS、DIN和帧末sample_tick，新增仅供内部计算的sample_prepare_tick：发送上一帧最后一位的下降沿开始准备下一帧。顶层音频使用这个48kHz使能，距新帧锁存约64～65个100MHz周期，覆盖新增混音流水线。完整四音色DAC仿真逐帧强制检查第56周期已稳定、锁存前未变化及2083/2084周期的采样间隔，避免因检查时刻晚于锁存而漏检。

力度曲线使用原PCM弱音补偿，电子琴波表在同一曲线上预乘0.55，避免波表稳定振幅与录音起音峰值造成巨大响度差。所有增益在LUT生成时确定，不额外增加实时乘法。新吉他/萨克斯录音按原电钢琴前200ms RMS标定，峰值限制为约0.70满幅；原电钢琴147库逐字节保留。峰值压缩、分音色响度校准、力度层和用户VOL分别承担不同作用。

数学极值/随机混音、PCM尾部、全部441库寻址、4音色实际48kHz DAC帧、力度/踏板/短释放均有专门仿真或资产检查。具体通过状态以最终verification为准，实物感知响度与大和弦失真仍需上板试听；不能把RMS校准表述为听感完全一致。
