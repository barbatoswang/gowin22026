针对键盘演奏、节奏练习与数字音频实验，设计了一套以FPGA为实时发声核心的多音色电子乐器系统。49键MIDI输入在FPGA内完成协议解析、32声部分配、周期波表插值、独立包络、混音和数字音效。电钢琴、吉他、萨克斯与马林巴四选一，共用32声部引擎，以48kHz、16bit格式经PT8211输出。
LCD统一提供自由演奏、音色选择、曲谱示范与跟弹、事件录音和循环叠录入口。49颗RGB灯与LCD琴键采用统一映射，以黄蓝提示和绿红反馈辅助起音；评分依据音高与起音误差，显示逐音判定、连击和整曲等级。波形页展示七个活动声部贡献及总混音，频谱、延时相位李萨如和内部计时提供不同观察视角。
手机经BLE、ESP32-S3与UART传递事件和控制，支持八参数读写及按歌曲ID管理SD下载曲目。16槽事件录音保存音符、力度、时间和音色，回放重新合成；四层Loop Station将现场音频暂存DDR，按首段长度换乐器叠录，掉电清空。
